Drop white (or any colour — a CSS filter forces white) SVG logos here.

LogoMark loads in this order:
  1. /images/logos/{slug}.svg          ← if you provide one, this wins
  2. https://cdn.simpleicons.org/{slug}/ffffff   ← fallback (only some brands)
  3. nothing                            ← if both fail, the slot is hidden

Expected filenames:
  nike.svg
  volkswagen.svg
  audi.svg
  hugoboss.svg
  tommyhilfiger.svg
  unilever.svg
  johnsonandjohnson.svg
  royalmail.svg
  parcelforce.svg
  postoffice.svg
  fortnumandmason.svg
  falabella.svg
  palantir.svg

Where to find them:
  - Brand press kit / media centre on each brand's site
  - https://worldvectorlogo.com
  - https://www.vectorlogo.zone
  - https://seeklogo.com
  - Brand identity guidelines PDF

Save them with `.svg` extension and a transparent background.
